# SmartExpense 💰

Personal Expense Dashboard built with .NET 8, PostgreSQL and React.

SmartExpense is a web application for managing personal expenses and
visualizing spending information through a simple dashboard.

## 🚀 Technologies

### Backend
- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Swagger / OpenAPI

### Frontend
- React
- Vite
- Recharts

## ✨ Features

- Create expenses
- View expenses
- Update expenses
- Delete expenses
- Categorize expenses
- Register payment methods
- Dashboard with expense summary
- Expenses by category
- Interactive charts

## 🏗️ Project Structure

### SmartExpense.API
Controllers and API configuration.

### SmartExpense.Application
Services, DTOs and interfaces.

### SmartExpense.Domain
Entities and enums.

### SmartExpense.Infrastructure
Database configuration, repositories and migrations.

## 🗄️ Database

SmartExpense uses PostgreSQL with Entity Framework Core.

## 🖥️ Frontend

The frontend is developed separately using React, Vite and Recharts.

It provides the visual dashboard for managing and displaying expenses.
